# AutoRefine Baseline

## 1. Clone AutoRefine

```bash
git clone https://github.com/syr-cn/AutoRefine
```

This baseline uses `AutoRefine/run_autorefine_inference.py` to evaluate AutoRefine on a question-answering dataset and write predictions and evaluation details to the `results/` directory.

## 2. Setup

Install the dependencies required by the inference script in your Python environment:

```bash
pip install torch transformers sentence-transformers numpy accelerate
```

A CUDA GPU is recommended for running the 7B-parameter model. The script loads the language model in BF16.

Place `run_autorefine_inference.py` inside the cloned `AutoRefine/` directory if it is not already there. Run the following commands from the parent directory containing `AutoRefine/` and `data_baselines/`.

## 3. Required inputs

- **Questions JSON:** A JSON array of examples with a `question` (or `query`) field and an optional answer field (`answer`, `answers`, `ground_truth`, `gold`, or `target`).
- **Dense retrieval index:** A `.pkl` file containing `chunk_ids`, `embeddings`, and the associated chunk data. It should also contain `model_name` identifying the embedding model, unless `--encoder_model` is supplied.
- **Model checkpoint:** Use [`yrshi/AutoRefine-Qwen2.5-7B-Instruct`](https://huggingface.co/yrshi/AutoRefine-Qwen2.5-7B-Instruct) on Hugging Face (pass it explicitly via `--model_id`).

Example layout:

```text
project/
├── AutoRefine/
│   └── run_autorefine_inference.py
├── data_baselines/
│   ├── 2wiki_questions_500.json
│   └── 2wiki_index.pkl
└── results/
    └── 2wiki/
        └── autorefine.jsonl       # generated by inference
```

The questions and index files must be prepared separately; cloning AutoRefine does not by itself guarantee these files exist.

## 4. Run inference

From the `project/` directory:

```bash
python AutoRefine/run_autorefine_inference.py \
  --questions data_baselines/2wiki_questions_500.json \
  --index data_baselines/2wiki_index.pkl \
  --model_id yrshi/AutoRefine-Qwen2.5-7B-Instruct \
  --output results/2wiki/autorefine.jsonl \
  --topk 5
```

For a quick test on the first 10 questions:

```bash
python AutoRefine/run_autorefine_inference.py \
  --questions data_baselines/2wiki_questions_500.json \
  --index data_baselines/2wiki_index.pkl \
  --model_id yrshi/AutoRefine-Qwen2.5-7B-Instruct \
  --output results/2wiki/autorefine_test.jsonl \
  --limit 10
```

To resume an interrupted run without repeating question IDs already present in the output:

```bash
python AutoRefine/run_autorefine_inference.py \
  --questions data_baselines/2wiki_questions_500.json \
  --index data_baselines/2wiki_index.pkl \
  --model_id yrshi/AutoRefine-Qwen2.5-7B-Instruct \
  --output results/2wiki/autorefine.jsonl \
  --resume
```
